# 🌷 My Little Corner

*A little corner of the internet that feels like me.*

My Little Corner is a personal website built to explore web development through playful interactions, soft pastel aesthetics and creative UI design. It mixes personality with hands-on frontend practice in a space that is both fun and personal.

🌐 **Live website:** [Visit My Little Corner](https://dhritiiixpaw.github.io/my-little-corner/)


## 🖼️ Preview

![My Little Corner homepage](screenshots/Screenshot%202026-10-25%20211046.png)

## ✨ Features

- 🌷 **Mood check-in:** pick how you feel (happy, calm, tired, meh) and get a gentle response
- 📝 **Tiny tasks:** add small to-dos for the day, saved in your browser with `localStorage`
- 🦢 **Little journal:** a private note that stays in your browser until you clear it
- 💌 **Affirmations:** a "note to your heart" with a new reminder on request
- 🎭 **Choose your vibe:** an Angel / Menace toggle that changes the tone of the site
- 🍵 **The Tea Court:** a dramatic, playful corner for dropping your "lore"
- 🌙 **Theme customization:** switch to Moonlight (night) mode
- 📱 **Responsive design:** made to work on both desktop and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling, `localStorage`)
- GitHub Pages for hosting

## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/dhritiiixpaw/my-little-corner.git

   ```
2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No build step or dependencies needed.

## 💭 Why I Built It

I wanted to make something more personal than a traditional portfolio, with room to experiment with frontend development, interactive components and visual design. I also wanted a page that feels gentle and kind, somewhere a person having a rough day can land on something soft and colourful.

## 📚 What I Learned

- Handling user interactions with JavaScript events
- Saving and loading data in the browser with `localStorage`
- Building layouts that adapt to different screen sizes
- Giving a site a consistent personality through colour, type and copy

## 🌸 What's Next

- Refine the user experience and responsive layouts
- Add more playful interactions
- Keep improving accessibility (contrast, keyboard navigation, screen-reader labels)
